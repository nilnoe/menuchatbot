# ADR-0007：长时推演模式（区别于官方思考档位）

- 状态：已接受（2026-08-01，方向定稿）
- 关联：ADR-0006（工具验算）、TODO「Rust 核心与 AI 能力规划」Tier 5

## 背景

用户所指「深度思考」不是官方 `reasoning_effort`（服务端控制单次思考强度，
思考预算由模型内部决定，`budget_tokens` 被忽略），而是让 AI 对复杂问题
**持续思考更长时间**（如 20 分钟以上），以提升复杂推理准确率。

## 决策

### D1：不依赖单次超长请求

单次流式思考受连接稳定性、输出上限（默认 64k / 最大 384k token）与服务端
行为制约，无法承诺「一次请求思考 20 分钟」。以此为主形态风险高且不可控。

### D2：长时推演 = 客户端编排的多阶段循环

规划 → 展开 → 工具验算（T0 计算器 / T1 只读 / T2 脚本）→ 自评 → 修正 →
综合；每轮为正常 API 调用，App 负责调度、进度展示与预算控制。这是
self-refine / self-consistency 的工程化变体，不是自治 Agent。

### D3：时间预算驱动

用户可选 5 / 10 / 20 / 30 分钟（或按 token 预算）推演时长；App 后台推进，
实时展示推理进度与当前阶段，超预算自动收敛；可随时停止且保留已完成内容。

### D4：护栏

发起前估算 token / 费用（`TokenUsage` 已有费用模型）并提示；流式中断可续跑
（部分推演内容沉淀到会话 reasoning 展示）；深度模式默认关闭。

### D5：已知风险

长思考收益递减；研究显示**截断的思考链可能劣于不思考**。因此推演过程不
截断、按问题类型使用（数学证明 / 复杂推理收益高，常识问答无意义）。

### D6：自检与长时推演解耦

「生成后第二遍验证」（成本约 ×2，可配置）是独立开关，与长时推演分开：
前者轻量（秒级），后者重量（分钟级），用户按需选择。

## 后果

**正面**：真正实现「可控制时长的深度思考」，思考过程可见、成本可预估。

**代价**：实现复杂度最高（编排循环 + 预算 + 断点续跑 + 进度 UI），成本随
时长上升，收益视问题类型而定。

## 备选方案

- 单次 `effort=max` 长输出：实现最简单，但无法控制时长且收益不可控，
  作为 v1 过渡。
- 完整自治 Agent（自主拆任务、自主执行）：与「不做 Agent」诉求冲突，否决。
