# ADR-0005：本地资料库 RAG（命名资料库 + 授权 + 检索注入）

- 状态：已接受（2026-08-01，方向定稿）
- 关联：ADR-0004、TODO「Rust 核心与 AI 能力规划」

## 背景

用户希望 AI 参考指定目录下的本地资料（工作文档、技术笔记等）以提高回答
准确性。只检索用户指定的路径，不做全盘索引（慢且无意义）。

## 决策

### D1：命名资料库（named corpora）

设置中以「名称 + 路径 + 启用开关」列表维护（类环境变量语义）；支持按库
检索与过滤，回答可引用库名，用户能看清索引范围。

### D2：授权与路径安全

目录经 `NSOpenPanel` 选择并持久化 security-scoped bookmark（TCC 首次授权）；
所有索引与读取前做规范化 + symlink 解析后的**路径包含检查**，拒绝逃逸路径。

### D3：索引为派生数据，增量可重建

扫描跳过隐藏 / 二进制 / 超大文件，扩展名白名单；按标题 / 段落分块
（约 500~800 token，带重叠）；以 `path + mtime + contentHash` 增量更新。
启动时扫描 + 手动「重新索引」；FSEvents 自动监听后置。

### D4：检索注入与引用复用

查询 embed → top-k 相似块 → 按文件去重 → 设定 token 预算（建议 4~8k）与
相关性阈值后注入上下文；命中文件**复用现有 `Source` 模型**展示为参考来源
卡片（标题 = 文件名，url = 路径），UI 零新增概念。

### D5：embedding 来源

本地小模型（candle，可 int8 量化）为默认，远程 OpenAI 兼容 embedding 预留为
可配置项；embedding 维度与模型 id 写入索引 schema 版本，换模型触发重建。

### D6：隐私与总开关

检索到的内容会随请求发往 API，这是功能本质：提供资料库总开关与按库开关，
UI 明示该行为。

## 后果

**正面**：检索范围受控、索引可重建、引用展示复用现有能力。

**代价**：本地 embedding 模型体积（约百 MB 级，int8 可缩小）；首次索引耗时
需后台分批 + 进度展示。

## 备选方案

- 全盘索引：明确否决（慢且无意义，且与「只读指定库」诉求冲突）。
- 仅存路径字符串、不授权：macOS TCC 下不可行，否决。
